## Запуск

Нужен PHP 8.2+ с расширениями bcmath и mbstring. Из корня репозитория:

```bash
php -m
python -B ports/check.py php
```

## Пример

```php
require 'ports/php/bootstrap.php';

use function Ports\Algorithms\Sorting\mergeSort;
use Ports\DataStructures\Trees\RedBlackTree;

$ordered = mergeSort([3, -1, 3, 0]);
$tree = new RedBlackTree();
foreach ($ordered as $value) $tree->insert($value);
print_r($tree->toArray());
```

Дерево возвращает `[-1, 0, 3]`: сортировка сохраняет повторения, структура множества исключает дубликаты. C#-пример выполняется в консольном проекте с ProjectReference на Algorithms.csproj. Go-пример поместите в отдельный каталог внутри модуля ports/go и запустите `go run .`.

## Типы и особенности API

bootstrap.php загружает функции и регистрирует автозагрузку классов. Имена функций и методов повторяют camelCase исходной коллекции. Большие целые возвращаются десятичными строками через BCMath. Строковые алгоритмы сопоставляют позиции UTF-16; Trie и ряд поведенческих паттернов используют символы Unicode. Map и Set из shared/collections.php сохраняют тип ключа и идентичность объектов. Асинхронные паттерны используют shared/promise.php: завершённую операцию можно await сразу, ожидающую — внутри Fiber. Внешний код должен завершить Promise через resolve или reject; собственного цикла событий нет. Задержка Retry блокирует поток через usleep.

## Проверки

Проверяются все 140 файлов и соответствие экспортов, 64 общих эталонных примера, 2000 операций вставки и удаления на сбалансированных деревьях и сценарии паттернов. Эти проверки не охватывают все ветви каждого модуля.
