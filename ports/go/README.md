## Пример

```go
package main

import (
    "fmt"
    "algs/algorithms/sorting"
    "algs/data-structures/trees"
)

func main() {
    ordered := sorting.MergeSort([]int{3, -1, 3, 0})
    tree := trees.NewRedBlackTree[int]()
    for _, value := range ordered { tree.Insert(value) }
    fmt.Println(tree.ToArray())
}
```

Дерево возвращает `[-1, 0, 3]`: сортировка сохраняет повторения, структура множества исключает дубликаты. C#-пример выполняется в консольном проекте с ProjectReference на Algorithms.csproj. Go-пример поместите в отдельный каталог внутри модуля ports/go и запустите `go run .`.

## Типы и особенности API

Модуль называется algs. Публичные функции используют PascalCase и стандартные сокращения BFS, DFS, GCD. Большие целые возвращаются как math/big.Int. Индексы строковых алгоритмов согласованы с UTF-16. Для отсутствующего результата обычно возвращается пара (значение, bool), для ошибок сервисов — (значение, error). Repository требует метод GetID() string, использует собственную функцию копирования или JSON для экспортируемых полей. Pipeline и Repository синхронны; вызывающая программа может запускать их в goroutine. Promisify возвращает канал результата. Подписчики представлены указателями на Listener или Observer, чтобы удаление подписки сохраняло идентичность. Из-за ограничения обобщённых методов UsePool и Accept объявлены отдельными функциями. Для DI предусмотрены типизированные NewToken, Register и Resolve.

Сигнатуру конкретной реализации смотрите по ссылке из каталога.
