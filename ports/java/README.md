## Сборка и использование

Из корня репозитория выполните:

```bash
python -B ports/java/check.py
```

Скрипт компилирует исходники и проверки в `dist/java-classes`. Чтобы запустить свой пример, сохраните следующий код в `dist/Example.java`:

```java
import java.util.List;
import algorithms.sorting.MergeSort;
import algorithms.dynamic_programming.Fibonacci;
import data_structures.trees.RedBlackTree;

public class Example {
    public static void main(String[] args) {
        System.out.println(MergeSort.mergeSort(List.of(3, -1, 3, 0)));
        var tree = new RedBlackTree.Tree<Integer>();
        tree.insert(3);
        tree.insert(1);
        tree.insert(2);
        tree.delete(3);
        System.out.println(tree.toArray());
        System.out.println(Fibonacci.fibonacciFast(100));
    }
}
```

```bash
javac -cp dist/java-classes -d dist/java-classes dist/Example.java
java -cp dist/java-classes Example
```

Результаты: `[-1, 0, 3, 3]`, `[1, 2]`, `354224848179261915075`.

## Как устроены решения

[Сортировка слиянием](src/algorithms/sorting/MergeSort.java) работает с `List<T>` и компаратором. Она сортирует половины и собирает новый список, выбирая левый элемент при равенстве. Время `O(n log n)`, дополнительная память `O(n)` для списков с доступом по индексу за `O(1)`.

[Красно-чёрное дерево](src/data-structures/trees/RedBlackTree.java) хранит узлы с родителями и цветами, балансирует их поворотами и перекрашиванием. Вставка и удаление возвращают признак изменения множества. Поиск, вставка и удаление занимают `O(log n)`; `toArray()` возвращает отсортированный список.

[Фибоначчи](src/algorithms/dynamic-programming/Fibonacci.java) включает рекурсивный, мемоизированный, итеративный варианты и быстрое удвоение. Последний использует `BigInteger` и выполняет `O(log n)` шагов; арифметика больших чисел имеет дополнительную стоимость.

[Команда](src/patterns/behavioral/Command.java) отделяет изменение документа от истории действий. Вставка и удаление сохраняют данные для обратной операции, макрокоманда отменяет вложенные действия в обратном порядке. После нового действия история повторного выполнения очищается.

Пояснения ко всей коллекции находятся в [основном README](../../README.md), ссылки на каждый модуль — в [каталоге](../CATALOG.md).

## Соглашения

- Пакеты соответствуют категориям: `algorithms.sorting`, `data_structures.trees`, `patterns.behavioral`. Дефис в имени каталога заменяется подчёркиванием в имени пакета.
- Функции исходного модуля представлены статическими методами одноимённого класса: `MergeSort.mergeSort`, `Fibonacci.fibonacciFast`. Некоторые структуры находятся во вложенных классах, например `RedBlackTree.Tree<T>` и `BTree.Tree<T>`.
- Обобщённые коллекции используют `List<T>` и `Comparator<T>`, числовые алгоритмы также принимают массивы примитивов. Тип аргумента проверяйте по сигнатуре выбранного метода.
- Для больших точных целых используется `BigInteger`; обычные численные вычисления используют `double`. Индексы строковых алгоритмов соответствуют UTF-16.
- Асинхронные паттерны возвращают `CompletableFuture`; результат примера можно получить через `join()`. Он оборачивает ошибку операции в `CompletionException`.

## Проверка

[check.py](check.py) компилирует все модули, запускает 64 общих эталонных примера и 2000 случайных операций на трёх сбалансированных деревьях. Дополнительно проверяет отмену команд, интерпретатор, состояния заказа, обработку JSON, singleton в контейнере зависимостей и повторные попытки. Полного покрытия всех ветвей каждого модуля этот набор не обещает.
