## Запуск

Нужен актуальный стабильный Rust с Cargo. Зависимости num-bigint, num-traits и serde_json зафиксированы в Cargo.lock.

```bash
cargo test --manifest-path ports/rust/Cargo.toml --locked
python -B ports/check.py rust
```

## Пример

В отдельном Cargo-проекте добавьте зависимость с путём до каталога ports/rust:

```toml
[dependencies]
algorithm-collection = { path = "../algs_and_structures/ports/rust" }
```

В src/main.rs:

```rust
use algorithm_collection::{
    algorithms::{
        sorting::merge_sort::merge_sort,
        dynamic_programming::fibonacci::fibonacci_fast,
    },
    data_structures::trees::red_black_tree::RedBlackTree,
};

fn main() {
    let ordered = merge_sort(&[3, -1, 3, 0], i32::cmp);
    let mut tree = RedBlackTree::new(i32::cmp);
    for value in ordered {
        tree.insert(value);
    }
    println!("{:?}", tree.to_array());
    println!("{}", fibonacci_fast(100));
}
```

Результаты: `[-1, 0, 3]` и `354224848179261915075`. Дерево исключает повторения, сортировка сохраняет их. Обобщённые алгоритмы получают функцию сравнения; для f64 используйте f64::total_cmp.

## Типы и особенности API

Функции и методы используют snake_case, названия структур сохраняют исходные имена. Классы без конструктора в TypeScript представлены структурами с публичными полями или Default. Отсутствующий результат — Option, ошибки сервисов и паттернов — Result. Некорректные размеры, индексы и другие нарушения предусловий алгоритмов обычно вызывают panic через assert. Структуры коллекций возвращают ссылки, владение извлечённым значением или Vec в зависимости от операции.

Большие целые возвращаются как num_bigint::BigInt; для JSON преобразуйте их в строку. Индексы строковых алгоритмов и редактора согласованы с UTF-16, Trie и Huffman обходят символы Unicode. Rust String не хранит отдельные суррогаты: срез, разрывающий пару UTF-16, заменяет неполный символ на U+FFFD.

Там, где TypeScript возвращает объект, Rust может возвращать структуру или кортеж: например, linear_sieve возвращает (primes, smallest_factor), а методы Graph — (vertices, matrix) и (vertices, list). Деревья принимают Comparator<T> и предоставляют iter(). Красно-чёрное дерево использует LLRB-балансировку; B-дерево выполняет расщепление, заимствование и слияние узлов. Списки используют безопасные индексные арены; повторное использование узлов двусвязного списка защищено поколением NodeHandle.

Паттерны владения используют Box, Rc и RefCell. Observer<T> — Rc<dyn Fn(&T)>; повторная подписка того же Rc сохраняет идентичность обработчика. DI возвращает клонированное T, поэтому для общей идентичности сервиса используйте Token<Rc<Service>>. Factory контейнера возвращает Result<T, String>, что позволяет передавать ошибки разрешения зависимостей. Repository требует Entity::id(), по умолчанию использует Clone; для полей с разделяемым владением передайте функцию глубокой копии.

Некоторые имена адаптированы: Editor::type_text, ObjectPool::use_item, Pipeline::use_middleware. with_logging принимает список serde_json::Value и возвращает Value. combine_reducers сравнивает значения JSON, а не идентичность ссылок. Версии API и соответствие имён доступны в [coverage.json](coverage.json).

## Асинхронные паттерны

Proxy, Repository, CircuitBreaker, retry и Pipeline используют Future и await. Runtime программа выбирает самостоятельно. CircuitBreaker::call принимает один аргумент; несколько параметров можно объединить в кортеж. Заимствование &mut self исключает одновременные изменяющие операции с одним предохранителем.

Middleware получает Rc<RefCell<C>> и Next. Освобождайте заимствование контекста до await; вызов next() дважды возвращает ошибку. Promisify адаптирует callback к std::sync::mpsc::Receiver<Result<T, String>>. Положительная задержка retry использует std::thread::sleep и блокирует текущий поток; для включения в неблокирующий runtime можно запускать эту операцию на отдельном рабочем потоке.

## Проверки

[check.py](check.py) сверяет наличие всех 140 модулей и экспортов и запускает Cargo с зафиксированными зависимостями. Набор включает:

- [64 общих эталонных примера](tests/conformance.rs).
- [200 тысяч операций на деревьях, 2000 запросов на отрезках, коллизии хеш-таблиц, LRU и списки](tests/structures.rs).
- [Сравнение кратчайших путей, остовов и компонент на случайных графах](tests/graphs.rs).
- [Сценарии паттернов, подписки, копирование, ошибки DI, middleware и восстановление предохранителя](tests/patterns.rs).

Проверки сопоставляют результаты разных алгоритмов и стандартных коллекций и проверяют инварианты после операций. Набор не покрывает все ветви каждого модуля.
