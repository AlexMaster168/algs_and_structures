## Запуск

Нужен компилятор с поддержкой C++20: GCC, Clang или совместимый инструмент. Проверки используют g++.

```bash
python -B ports/check.py cpp
```

## Пример

Сохраните example.cpp в корне репозитория:

```cpp
#include "ports/cpp/algorithms/sorting/merge-sort.hpp"
#include "ports/cpp/algorithms/dynamic-programming/fibonacci.hpp"
#include "ports/cpp/data-structures/trees/red-black-tree.hpp"
#include <iostream>

int main() {
    auto ordered = algs::mergeSort(std::vector<int>{3, -1, 3, 0});
    algs::RedBlackTree<int> tree;
    for (int value : ordered) tree.insert(value);
    for (int value : tree) std::cout << value << ' ';
    std::cout << '\n' << algs::fibonacciFast(100) << '\n';
}
```

```bash
g++ -std=c++20 example.cpp -o example
./example
```

Результаты: `-1 0 3` и `354224848179261915075`. Дерево исключает повторения, сортировка сохраняет их.

## Типы и особенности API

Обобщённые алгоритмы принимают std::vector<T> и Comparator<T>, числовые алгоритмы — Numbers (std::vector<double>). При поиске элемента в обобщённой коллекции тип искомого значения должен совпадать с T. Отсутствующий результат представлен std::optional; коллекции обычно возвращаются по значению. Большие целые представлены [BigInt](bigint.hpp), который поддерживает арифметику произвольной точности и преобразование str().

Строковые алгоритмы и позиции редактора работают с байтами std::string; для UTF-8 позиции отличаются от индексов UTF-16 в TypeScript. Huffman выделяет символы UTF-8. [Json](shared/json.hpp) поддерживает объекты, массивы, числа, строки и Unicode-экранирование; используется в Builder, экспорте фигур и проверках.

Методы, совпадающие с ключевыми словами C++, переименованы: deleteValue, registerProvider, registerPrototype, andSpec, orSpec, notSpec. Геттеры доступны как методы size(), state(), rootNode(). Prototype возвращает unique_ptr; фабрики и подписки используют shared_ptr там, где нужна общая идентичность.

Паттерны асинхронных операций используют std::future. CircuitBreaker принимает один аргумент A: несколько параметров можно объединить в std::tuple. Во время выполняющейся операции сервисы, контекст Pipeline и объект предохранителя должны оставаться живыми. Repository по умолчанию копирует T; если T содержит разделяемые указатели и нужна глубокая копия, передайте функцию clone. Подписки представлены shared_ptr<Observer<T>>, что позволяет повторно использовать и удалять тот же обработчик. TypedEventEmitter<T> группирует события с одинаковым типом полезной нагрузки.

NumberRange, обходы TreeItem и take вычисляют значения при итерации; коллекция корневых узлов должна оставаться живой до завершения обхода. LLRB-вариант красно-чёрного дерева поддерживает левый наклон красных рёбер, сохраняя логарифмическую высоту. B-дерево выполняет расщепление, заимствование и слияние узлов.

## Проверки

[check.py](check.py) сверяет соответствие 140 модулей и экспортов, компилирует все заголовки вместе, затем выполняет [64 общих эталонных примера](tests/conformance.cpp), [200 тысяч операций на деревьях](tests/trees.cpp) и [сценарии всех категорий паттернов](tests/patterns.cpp). Проверки деревьев сравнивают множество значений и инварианты балансировки после каждой операции; B-деревья проверяются для степеней от 2 до 8. Набор не охватывает каждую ветвь всех модулей.
