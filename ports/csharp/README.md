## Запуск

Нужен .NET SDK 9.0+. Из корня репозитория:

```bash
dotnet build ports/csharp/Algorithms.csproj
python -B ports/check.py csharp
```

## Пример

```csharp
using Algorithms.Sorting;
using Algorithms.DataStructures.Trees;

var ordered = Sort.MergeSort(new[] { 3, -1, 3, 0 });
var tree = new RedBlackTree<int>();
foreach (var value in ordered) tree.Insert(value);
Console.WriteLine(string.Join(", ", tree.ToArray()));
```

Дерево возвращает `[-1, 0, 3]`: сортировка сохраняет повторения, структура множества исключает дубликаты. C#-пример выполняется в консольном проекте с ProjectReference на Algorithms.csproj. Go-пример поместите в отдельный каталог внутри модуля ports/go и запустите `go run .`.

## Типы и особенности API

Имена публичных методов используют PascalCase. Общие алгоритмы принимают IReadOnlyList<T> и возвращают массивы; пустой результат поиска может быть nullable. Большие целые представлены System.Numerics.BigInteger, строковые алгоритмы работают с UTF-16. Асинхронные паттерны возвращают Task<T>; для нескольких аргументов предохранителя используйте кортеж. Пространства имён алгоритмов начинаются с Algorithms, паттернов — с Patterns. Для репозитория можно передать собственную функцию копирования; стандартная копия использует System.Text.Json.

Алгоритмические идеи общие для языков: например, слияние сортирует половины и объединяет их за O(n log n), Фенвик хранит частичные суммы для обновлений за O(log n), красно-чёрное дерево поддерживает высоту O(log n) через перекрашивания и вращения. Сигнатуру конкретной реализации смотрите по ссылке из каталога.

## Проверки

Проверяются все 140 файлов и соответствие экспортов, 64 общих эталонных примера, 2000 операций вставки и удаления на сбалансированных деревьях и сценарии паттернов. В PHP дополнительно выполняются 1000 проверок обновлений и запросов на отрезках. Эталонные примеры находятся в [golden-cases.json](../golden-cases.json). Эти проверки не охватывают все ветви каждого модуля.
