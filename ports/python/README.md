## Использование

Импорты выполняются из корня репозитория:

```python
from ports.python.algorithms.sorting.merge_sort import merge_sort
from ports.python.algorithms.graphs.dijkstra import dijkstra
from ports.python.algorithms.dynamic_programming.fibonacci import fibonacci_fast
from ports.python.data_structures.trees.red_black_tree import RedBlackTree

print(merge_sort([3, -1, 3, 0]))
graph = [
    [{'to': 1, 'weight': 2}, {'to': 2, 'weight': 8}],
    [{'to': 2, 'weight': 3}],
    [],
]
print(dijkstra(graph, 0)['distance'])
tree = RedBlackTree()
for value in [3, 1, 2]:
    tree.insert(value)
tree.delete(3)
print(tree.to_array())
print(fibonacci_fast(100))
```

Результаты: `[-1, 0, 3, 3]`, `[0, 2, 5]`, `[1, 2]`, `354224848179261915075`.

## Как устроены решения

[Сортировка слиянием](algorithms/sorting/merge_sort.py) делит последовательность пополам и сливает отсортированные части двумя указателями. При равенстве берёт левый элемент, сохраняя стабильность. Возвращает новый список; время `O(n log n)`, дополнительная память `O(n)`.

[Дейкстра](algorithms/graphs/dijkstra.py) извлекает вершину с минимальным расстоянием из собственной бинарной кучи и улучшает расстояния до соседей. Устаревшие записи в куче пропускаются. Требует неотрицательных весов, возвращает расстояния и родителей для восстановления пути; время `O((V + E) log V)` для простого графа, память `O(V + E)` с очередью повторных записей.

[Красно-чёрное дерево](data_structures/trees/red_black_tree.py) сохраняет ограничения на цвета и чёрную высоту поворотами и перекрашиванием после вставки и удаления. Повторные значения не добавляются. Поиск, вставка и удаление занимают `O(log n)`; `to_array()` выдаёт значения по порядку за `O(n)`.

[Быстрое вычисление Фибоначчи](algorithms/dynamic_programming/fibonacci.py) рекурсивно вычисляет пару соседних чисел для половины индекса, затем восстанавливает ответ формулами удвоения. Выполняет `O(log n)` шагов, используя целые числа произвольной точности. Стоимость арифметики растёт с числом разрядов результата.

Для остальных решений пояснения и примеры находятся в [основном README](../../README.md), прямые ссылки на каждый модуль — в [каталоге](../CATALOG.md).

## Соглашения

- Функции и методы используют `snake_case`, классы — `PascalCase`: `mergeSort` → `merge_sort`, `toArray` → `to_array`. Соответствие экспортов хранится в [coverage.json](coverage.json).
- Компаратор возвращает отрицательное число, ноль или положительное число. Его стандартная реализация находится в [shared/compare.py](shared/compare.py).
- Числовые массивы представлены списками. Графы используют списки соседей; взвешенное ребро — словарь с ключами `to` и `weight`. Результаты могут содержать словари с ключами в `snake_case`, например `smallest_factor`.
- `int` сохраняет точность больших целых чисел. Python-строки индексируются по символам Unicode; числовой индекс символа вне BMP отличается от индекса UTF-16 в TypeScript и JavaScript.
- Асинхронные паттерны используют корутины. Методы репозитория, circuit breaker и цепочки middleware нужно вызывать через `await`.

## Проверка

Асинхронный вызов с повторными попытками:

```python
import asyncio
from ports.python.patterns.architectural.circuit_breaker import retry

async def load():
    return {'value': 42}

async def main():
    result = await retry(load, attempts=3, delay_ms=10)
    print(result)

asyncio.run(main())
```

Из корня репозитория:

```bash
python -B ports/python/check.py
```

Проверка импортирует все 140 модулей и сверяет доступность экспортов, выполняет 64 общих эталонных примера, 2000 случайных операций на AVL-, B- и красно-чёрном деревьях, проверяет команды с отменой, интерпретатор, переходы состояния, повторные попытки и восстановление circuit breaker. Это набор проверок переноса; полного покрытия всех ветвей каждого модуля он не обещает.
